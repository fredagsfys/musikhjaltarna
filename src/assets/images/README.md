# Images

Drop the Variant D art here. Components pick each file up by name and fall back to a
placeholder until it exists. Prefer transparent PNG for characters; Astro generates
AVIF/WebP and responsive sizes at build time.

| File name (any extension) | Content                                                       | Used in                              |
| ------------------------- | ------------------------------------------------------------- | ------------------------------------ |
| `emblem`                  | Musikhjältarnas round emblem                                  | Header, pedagogue, pricing           |
| `gilbert-guide`           | Gilbert G-klav half figure, transparent background            | App example, thank-you step          |
| `gilbert-thumbs-up`       | Gilbert G-klav giving a thumbs up, transparent background     | Everyday section, purchase flow card |
| `suzana-and-gilbert`      | Photo of Suzana Spasevska Hermansen with Gilbert G-klav (4:5) | Pedagogue section                    |
